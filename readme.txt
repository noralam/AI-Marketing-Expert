Instead of juggling expensive subscriptions for Apollo/Hunter, Mailchimp, Jasper, Semrush, Hootsuite, Intercom, CartBounty, and Zapier, you get everything inside your WordPress admin — B2B lead finder, email marketing, content generation, SEO analyzer, social media scheduler, AI chatbot, workflow automation, and WooCommerce abandoned cart recovery.

Powered by your choice of leading AI models (ChatGPT, Claude, Gemini, or OpenRouter), every module is designed to save hours each week and grow your audience consistently.

== Installation ==

**From the WordPress Plugin Directory:**

1. Go to **Plugins → Add New** in your WordPress admin
2. Search for **AI Marketing Expert**
3. Click **Install Now** and then **Activate**
4. Click **AI Marketing** in the left admin menu to get started

**Manual Installation:**

1. Download the plugin zip file
2. Go to **Plugins → Add New → Upload Plugin**
3. Upload the zip and click **Install Now**
4. Activate and go to **AI Marketing** in your admin menu

**Setup:**

1. Go to **AI Marketing → Settings → AI Providers** and add at least one AI connection (Google AI Studio is free to start)
2. Enable the modules you want from the Modules screen
3. Configure each module from its submenu page

== Frequently Asked Questions ==

= Does this plugin require an API key? =

AI-powered features (content generation, AI subject lines, chatbot, SEO analysis, social captions) require an AI provider API key. You can use Google AI Studio (Gemini) which offers a free tier, or OpenAI, Anthropic Claude, or OpenRouter. Non-AI features like SMTP email sending and subscriber management work without any API key.

= Which AI provider should I start with? =

Google AI Studio (Gemini) is the easiest to start with — it offers a free API tier with no credit card required. Sign up at ai.google.dev, create an API key, and paste it into AI Marketing → Settings → AI Providers.

= Is the email marketing feature really free with unlimited subscribers? =

Yes. It includes unlimited subscribers and unlimited email campaigns. There is no artificial subscriber or campaign cap.

= Does the chatbot work with WooCommerce? =

Yes. You can index your WooCommerce product catalog into the chatbot knowledge base so it can answer product questions, check availability, and assist shoppers automatically.

= Can I use multiple AI providers at the same time? =

Yes. You can add multiple AI provider connections and assign different providers to different modules — for example, GPT-4o for content generation and Claude for your chatbot.

= Will this plugin slow down my website? =

No. All AI calls and email sending happen in the WordPress admin or via background WP-Cron jobs. The only front-end asset is the optional chatbot widget, which loads asynchronously.

= Does the social media scheduler support LinkedIn? =

Yes. The social scheduler supports LinkedIn personal profiles and company pages alongside Facebook Pages, Instagram Business, and X (Twitter).

= Is my data secure? =

Yes. All API keys and SMTP credentials are encrypted at rest using AES-256-GCM authenticated encryption. Subscriber lists and contact records remain strictly on your own WordPress server. Chatbot queries and prompt instructions are transmitted to your configured AI provider only to generate replies, with visitor opt-in consent enabled by default. Email tracking uses HMAC-signed URLs to prevent open redirect abuse.

= Can I import existing email subscribers? =

Yes. You can import subscribers from a CSV file, sync from WordPress registered users, or import WooCommerce customers.

= Where can I get support? =

Visit [wordpress.org/support/plugin/ai-marketing-expert/](https://wordpress.org/support/plugin/ai-marketing-expert/) for documentation and support.

== Source Code & Build Instructions ==

All unminified JavaScript (`.js`, `.jsx`) and SCSS/CSS (`.scss`, `.css`) source files for compiled assets in `build/` are included directly inside `src/`, along with `package.json` and `webpack.config.js`.

Public development repository: https://github.com/noralam/AI-Marketing-Expert

Build instructions:
1. Ensure Node.js (version 18+) and npm are installed.
2. In the plugin root, run `npm install` to install dependencies.
3. Run `npm run build` to compile production assets into `build/` (or `npm start` for development).

== Privacy Policy ==

AI Marketing Expert connects to external services only when configured and initiated by an administrator or site visitor:
* **AI Chatbot & Visitor Privacy:** Visitor messages and conversation context are transmitted to your configured AI provider solely to generate contextual answers. A GDPR-compliant visitor opt-in consent notice is enabled by default. Personal visitor emails are never transmitted to AI providers.
* **Subscriber & Customer Data:** All email subscriber records, lists, tags, and campaign metrics are stored strictly within your local WordPress database.
* **Encryption at Rest:** All API credentials, secret tokens, and SMTP passwords are encrypted at rest using AES-256-GCM authenticated encryption.
