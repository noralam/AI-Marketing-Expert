All-in-one AI-powered marketing toolkit for WordPress.

== Description ==

AI Marketing Expert provides email marketing, content generation, social media management, chatbot, SEO, and analytics tools from the WordPress dashboard.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/ai-marketing-expert` directory, or install the plugin through the WordPress plugins screen.
2. Activate the plugin through the Plugins screen in WordPress.
3. Open AI Marketing in the WordPress admin menu to configure the plugin.

== Frequently Asked Questions ==

= Does this plugin require an AI provider? =

Some AI-powered features require configuring an AI provider from the plugin settings.
